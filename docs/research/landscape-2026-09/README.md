# Landscape of Great Schools: research, September 2026

Draft 0.1 of UnconstrainED's working framework, which has no name yet, plus the five AI research reports behind it. The research was run by Claude agents for UnconstrainED on 24 September 2026. It has not been verified yet: check each claim against its source before using it with a client.

- `landscape-framework-draft-0.1-full.html`: the framework plus all five reports as appendices. Open it in a browser.
- `A-k12.md`: K-12 schools
- `B-higher-education.md`: higher education
- `C-professional-learning.md`: professional and workplace learning
- `D-evidence-and-frameworks.md`: the evidence base and existing frameworks
- `E-international-schools-brazil.md`: international schools, Brazil and Latin America

The framework on its own is also in Google Drive, as a Google Doc.
