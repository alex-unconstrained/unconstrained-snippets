# The UnconstrainED Tree: Master Framework v3

Version 3 of the master framework. It rebuilds v0.2 around a single metaphor, the tree, and replaces the old cycle diagram with the ring (Figure 1).

- `UnconstrainED_Master_Framework_v3_The_Tree.docx`: the document.
- `figures/ring.*`: Figure 1, the ring (the six movements as one growing cycle).
- `figures/tree.*`: the whole tree (trunk, roots, soil, three limbs, branches, saplings).
- `build-docx.js`: the script that generates the .docx (it uses the docx npm package). Edit the content here and rerun it to produce a new version.

The figures use the brand fonts. The .docx body falls back to Arial.
